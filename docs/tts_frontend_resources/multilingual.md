# 七语种数学与术语前端

中文保留现有解析器和已验证词表；英语、日语、德语、法语、俄语、西班牙语新增共同的有界数学语法和各自的读法。泰语暂缓。模型、TensorRT 引擎、音色、停止策略和降噪链路不因本功能改变。

`numbers` 模式在 tokenizer 和断句之前展开数学与显式单位。支持关系式、四则运算、括号、分数、幂、根式、常见三角/对数函数、上下标、百分数及科学计数法。各语种 60 余个大小写敏感单位符号采用 CLDR 长单位形式；例如 mW 与 MW 不合并。俄语处理数字性别、整数数量变化和十进制分数；德语、法语、西班牙语、俄语接受小数逗号。无歧义数学上下文之外，日期、时间、版本、路径、代码、URL、裸数字及不支持的表达式保留。

术语目录以现有公开 AI/LLM 词表为底，六语种各记录 269 项处理策略。完整词名保持身份，不把 BERT、CLIP、RAG、FLUX 等拆成字母，也不把英文术语整体替换成语义翻译。新增缩写读法进入 `trial`，仅 `numbers_terms` 启用；已有 approved/rejected 记录优先。词表覆盖数量不代表每项发音已通过验收。尤其英文 GPU 等历史退化项继续关闭。

资源：Unicode CLDR、Speech Rule Engine、NVIDIA NeMo text processing，以及 MathCAT 的俄语数学字母表。数学变量的俄语读法与技术缩写的英语字母读法分别维护。完整来源、版本、文件 SHA 与许可证见同目录 JSON 和 runtime NOTICE。数字通过系统 ICU 的稳定 C API 读取已安装规则，不引入 PyICU/Pynini 或新的声学模型。当前验证版本为 ICU70；Docker 构建检查系统库存在，其他 ICU 版本仍须验证。

边界：这是常见表达式的保守文本前端，未实现任意 LaTeX、矩阵、积分求解或整段自然语言的格变化。俄语单位使用独立计量短语的形式，未推断外部句子的全部语法格。ASR 对照只能定位疑似错漏，不能代替母语评审或证明外语自然度。展开后文本可能变长，因此还需检查真实断句、漏读、首音频和 RTF。

离线重建：在项目根目录运行 `.venv/bin/python -B phanthymotus/tools/import_tts_multilingual_resources.py --sources tmp/multilingual-sources-20261028`。输入是已有的公开源码快照；脚本不下载模型、构建引擎或提交榜单。
