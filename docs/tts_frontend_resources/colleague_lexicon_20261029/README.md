# 同事多语种候选词库（2026-10-29）

来源：用户提供的项目根目录 `lexicon.candidates.json`，原始 SHA256 见 `integration.json`。来源目录为同事的 multilingual-lexicon-20261029；本次未访问或修改其工作目录。

完整保留44条候选读法、16,442条术语库存、原来源信息及待复听验证记录。`candidates.json` 保存原文件除 inventory 外的全部字段；`inventory-*.json` 按原顺序分片，每份500条以内。按 inventory_files 顺序连接后能逐字段还原原文件；拆分仅为满足比赛每个 Git 文件不超过1MB的要求。

这是候选资源，不是已批准的发音规则。未接入默认推理或 numbers_terms 模式，也未传入 Nano 不支持的音素字段。继承 VITS2 的音素/中文替换仅作为历史参考，不能当作 Nano 可用读法。全部原有 enabled=false 和状态原样保留。

`integration.json` 按语种和大小写折叠后的词名（含现有别名）比较44条候选与当前运行词库，分为新候选、相同读法和冲突。它不是验证通过清单；即使已有词条为 rejected 或 trial 也不覆盖。中文 HAMi 的用户指定“哈密”等现有规则保留。泰语资料归档，但不扩大当前七语种测试范围。

后续在开发集建立独立候选对照，再按结果逐项写入 pronunciation_lexicon.json；不得在正在运行的500条/语种基线中途更换词库。原文件提到的同事音频/报告路径只是来源引用，未宣称本项目已取得或核验那些产物。
